                    Настройки

                    Экран вывода

                    Выберите монитор для окна вывода (Display).

                    Доступно только при выборе внешнего (не основного) монитора. Окно Display открывается при показе слайда или при включении этой опции.

                    Вывод слов в OBS

                    Добавьте в OBS источник «Браузер» и укажите адрес ниже: слова слайдов будут появляться в трансляции поверх видео. Фон оверлея прозрачный, поэтому текст виден только поверх других источников. Слова идут одной строкой, а размер шрифта подбирается так, чтобы они занимали источник целиком — задайте источнику размер того места на сцене, где должны быть слова (например 1920×1080 или 1920×200). В адрес можно добавить размер сцены (?w=1920&h=1080) и подложку под текст (?backdrop=0.4) — подложка из адреса сильнее настройки ниже.

                    Вывод выключен — слова в OBS не уходят.

                        Кликните по полю и нажмите нужную клавишу. Esc — отмена захвата. Изменения сохраняются в базу автоматически.

                          Резервные копии

                          Локальная копия сохраняется в выбранный файл, облачная — отправляется на Яндекс.Диск. Восстановление заменяет текущие данные содержимым выбранной копии.

                          Настройки Яндекс.Диска Токен не сохранён

                          Получите Client ID, пройдя по ссылке OAuth.yandex.ru, и вставьте его в соответствующее поле. Далее нажмите «Получить токен»: откроется страница Яндекса, где токен показан прямо в ответе — разрешите доступ, скопируйте токен в поле «OAuth-токен» и нажмите «Сохранить настройки».

                          Копии лежат в папке приложения на Яндекс.Диске: раздел «Приложения» → папка с именем вашего приложения → «имя папки/backups». Открывайте её можно кнопкой «Открыть папку с копиями на Диске».

                          Токен не сохранён — нажмите «Получить токен».

                          Журнал работы

                          Каждый запуск приложения создаёт отдельный файл журнала: в него попадают действия пользователя, обращения к базе, работа с видео и ошибки. Хранятся последние 10 файлов — самые старые удаляются автоматически.
