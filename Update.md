# Обновление приложения

Последняя опубликованная версия ChyguiSlide. Программа читает блок ниже при
запуске и сравнивает указанный в нём номер с установленной версией: если версия
новее, появляется окно «Доступно обновление».

```json
{
  "version": "0.1.3",
  "publishedAt": "13.09.2026",
  "mandatory": false,
  "notes": "Обновление в защищённых папках:\r\n- программа, установленная в C:\\Program Files или подобную папку, теперь обновляется по-настоящему: установщик запускается с правами администратора, и Windows запрашивает подтверждение;\r\n- раньше такое обновление заканчивалось «успешно», но файлы оставались прежними — новая версия попадала только в реестр, и программа продолжала показывать старую версию;\r\n- установка на новый компьютер (install.ps1) ставит программу в тот же каталог, где она уже стоит, и тоже с правами администратора, если папка защищена;\r\n- отказ от запроса прав обновление отменяет: программа остаётся открытой и сообщает об этом.\r\nМесто на диске:\r\n- скачанные файлы обновления удаляются после установки: раньше в кэше оставалось около 530 МБ (установщик и скачанная часть).",
  "downloadUrl": "https://github.com/DjgaaD/ChyguiSlide2/releases/download/v0.1.3/ChyguiSlide_0.1.3_x64-setup.exe",
  "sha256": "f6e341649acdae193be1a023ed73cf089ab40eca1571d7e5ca592030a4f96555",
  "sizeBytes": 278875000
}
```

## Формат блока манифеста

| Поле | Нужно | Назначение |
| --- | --- | --- |
| `version` | да | Версия релиза (`0.2.0`), сравнивается с версией приложения |
| `notes` | нет | Список изменений; строка, заканчивающаяся двоеточием, выводится заголовком |
| `publishedAt` | нет | Дата публикации, произвольный текст |
| `mandatory` | нет | `true` — обновление нельзя пропустить или отложить |
| `minSupported` | нет | Если установленная версия младше, обновление тоже обязательно |
| `downloadUrl` | нет* | Ссылка на один файл обновления: `.exe` установщика или `.zip` с ним |
| `parts` | нет* | Ссылки на части обновления по порядку (gzip-части крупного архива) |
| `sha256` | нет | SHA-256 собранного файла обновления в hex — так проверяется загрузка |
| `sizeBytes` | нет | Размер обновления в байтах, только для информации |

\* Нужно указать либо `downloadUrl`, либо `parts`.

## Ассеты релиза на GitHub

- `.exe` разрешён: установщик публикуется в релизе одним файлом, упаковка в
  архив не нужна.
- Предел размера одного файла — 2 ГБ (сборка весит около 270 МБ).
- Имена файлов в одном релизе должны быть уникальными.
- Файлы релиза должны быть доступны анонимно — так их и публикует
  `publish_github.ps1`, а доступность он проверяет после загрузки.

Если файл когда-нибудь придётся разбить на части, манифест переключается с
`downloadUrl` на `parts`: программа скачает части по порядку, распакует их
(gzip), склеит в один архив, проверит `sha256` и распакует установщик.

## Установка на новый компьютер

Скрипт `install.ps1` лежит в корне репозитория. Он читает блок манифеста выше и
делает всё то же, что делает приложение при обновлении: скачивает файл релиза,
проверяет `sha256` и запускает установщик. Пользователь выполняет одну строку в
PowerShell:

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/DjgaaD/ChyguiSlide2/master/install.ps1').TrimStart([char]0xFEFF)))
```

`.TrimStart([char]0xFEFF)` убирает BOM в начале файла — иначе PowerShell не
разберёт первую строку скрипта.

Скрипт публикуется рядом с `Update.md` и `README.md` тем же
`publish_github.ps1`. Ключи: `-SkipInstall` — собрать и распаковать без запуска
установщика, `-ManifestUrl <адрес|путь>` — взять манифест из другого места,
`-Silent` — установка без окон (`/S /UPDATE /R`).

Если программа уже установлена, скрипт ставит её в тот же каталог (путь берётся
из реестра), а в защищённой папке (`C:\Program Files` и подобных) запускает
установщик с правами администратора — Windows запросит подтверждение.
